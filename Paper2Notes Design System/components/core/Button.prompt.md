Chunky, pressable button that sits 3px proud of the page and sinks on press; use for every action.

```jsx
<Button variant="primary" icon="arrow-right">Next</Button>
<Button variant="sun" icon="gift">Claim</Button>
<Button variant="secondary" size="sm" iconOnly icon="rotate-ccw" label="Replay" />
```

- One primary per view. `sun` only for reward moments.
- Labels: 1–2 words, verb first. Icon-only needs `label`.
