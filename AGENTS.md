# AGENTS
- `paper2notes/notes/` -> visual-html-notes skill (three.js via js/diagrams3d.js, checks via js/checks.js, KaTeX). Open `notes/index.html` (landing) or `notes/book5/index.html` etc in browser, no build. Intake is `notes/_source/<book-ch>/` (ocr.md/outline.md/problems.md/images/INDEX.md). Landing at `/` lists Book 2/4/5 with inline SVG icons; no redirect (see `paper2notes/deploy/cloudrun/nginx.conf`).
- `paper2db/` -> pipeline (`./pipeline`). Source PDFs in `paper/{mc,lq,ans}/`, generated outputs in `tests/sections/{mc,lq,items}/`, `tests/reconstructed/`, `output/` / `classified/` (legacy) and `.lavish/` — gitignored. Tracked inputs are `metadata/*/llm_classifications.json`, `scripts/overrides_*.json`, `tests/reconstructed/lq/*/starts.json`, `tests/reconstructed/lq/*/ans_starts.json`. QB DOCX canonical is `paper2db/qb/` (migrated from paper2notes/qb), PDFs in `paper2db/qb-pdf/`.
- `paper2mock/` -> LaTeX mocks `paper2mock/f1/test1/<1..10>/`.
- DSE wiring: `paper2notes` is read-only consumer of `paper2db`. Published snapshot `paper2notes/notes/dse/{mc,lq}/<section>/` (82 files, tracked; staged to `_local` in `Dockerfile` since 361de93) ships to Cloud Run. For local `python -m http.server --directory paper2notes/notes` preview, run `./paper2db/pipeline --force --yes` then `./paper2notes/scripts/sync-dse.sh` to populate gitignored `paper2notes/notes/_local/dse/...` and `notes/book*/_local/dse/` (so `../_local/dse/...` resolves; or `cp -r notes/dse` to `_local`). HTML DSE decks (e.g. Book 5 25.1) render in production without sync; CI ignores `_local` via `isKnownLocalOnly`.

Keep `paper2notes/notes/**/_local/` and generated `paper2db/` files out of git; `paper2db/README.md` lists the reviewed JSON inputs that stay tracked. CI is `node paper2notes/scripts/ci-check.mjs` (validates `deploy-commit-footer` per HTML and protected-text leaks; see `paper2notes/deploy/cloudrun/README.md` and `paper2notes/scripts/leak-check.mjs`, plus anchor ids/`moves.json` and answer-pointer shape; see `paper2notes/anchors/README.md`). Deploy is `paper2notes/deploy/cloudrun` (injects `deploy-commit-footer` via `scripts/inject-commit-footer.mjs`).

UI PRs (paper2notes HTML/CSS/JS, visuals, animations, stage): load `.agents/skills/paper2everything-ui-screenshot/SKILL.md` before launch - before/after screenshots at BOTH laptop 1280×800 and mobile 390×844 required in PR body (one pair per size, same URL/scroll/viewport, attached via `gh --attach` so they render inline - one-size-only is incomplete; checklist in skill §7) and, if video demo, both sizes via `gh --attach` unless provably invisible at one (`.agents/skills/paper2everything-pr-video/SKILL.md` §5.1/§6).

Crop PRs (question, figure, table or answer crops, DSE or QB — `paper2notes/notes/qb/crops/**`, `paper2notes/notes/dse/**`, `paper2db/tests/sections/**` and pipeline outputs): load `.agents/skills/paper2everything-crop-screenshot/SKILL.md` before launch - representative PNG screenshots required in PR body (grid or sample, before/after where changed, readable resolution, uploaded as attachments so they render inline, checklist in skill section 7). Ship briefs for crop tasks (those touching `paper2notes/notes/qb/crops` or `paper2db` pipeline crops) must name this skill.
