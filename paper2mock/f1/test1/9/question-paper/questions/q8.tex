\question{8}{8} Ada is distributing stamps to $6$ friends. There are $112$ stamps with castle as background, $96$ stamps with sea as background and $50$ stamps with mountains as background.

\begin{subparts}
  \item Ada claims that she can distribute the stamps to all her friends evenly. Do you agree? Explain your answer.

  \item Ada now decides to pack the stamps into small bags. Only stamps with the same kind of background can be packed into the same bag. Each bag contains the same number of stamps.
  \begin{subpartsii}[1]
    \item At most how many stamps are there in each bag?
    \item Suppose the number of stamps in each bag is the same as the number found in (b)(i). How many bags does Ada need to pack all the stamps?
  \end{subpartsii}
\end{subparts}

\answerlines{13}
