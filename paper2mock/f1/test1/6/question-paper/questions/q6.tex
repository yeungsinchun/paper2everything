\question{6}{8} Terry wants to pack $45$ erasers, $75$ pencils and $120$ rulers into some boxes such that each box contains the same numbers of erasers, pencils and rulers respectively. Suppose no stationery is left.

\begin{subparts}
  \item Find the maximum number of boxes that Terry can pack.
  \item After packing the number of boxes in (a), Terry wants to add the same number of pens to each box so that the total number of stationery items in each box is $25$. Find the total number of pens that Terry needs.
\end{subparts}

\answerlines{17}
