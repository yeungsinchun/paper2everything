The single frame for every figure/animation on the site — white, 2px border, Fig badge, optional Replay, one-line caption.

```jsx
<FigureFrame num="1.2" caption="Displacement ignores the path." animated>
  <svg viewBox="0 0 480 240">…</svg>
</FigureFrame>
```

- Draw figures on a 480-wide viewBox using `--fig-*` colours and stroke tokens (see guidelines/figures).
