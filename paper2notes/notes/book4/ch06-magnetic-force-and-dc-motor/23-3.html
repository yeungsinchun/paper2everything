Section 23.3

Turning effect and the DC motor

A current loop in a field feels a couple; the motor keeps it turning.

ACoil as a couple

Key idea

Rectangular coil N turns area A in B: forces on two opposite sides form a couple torque \(\tau = N B I A \sin\phi\) (φ between normal and B; maximum when coil plane is parallel to B). Zero when plane perpendicular. The coil oscillates without commutation.

Key ideaDetail
FactorsTorque ∝ N, B, I, A.

Concept check

A 10-turn 5×5 cm coil carries 2 A in 0.1 T. Maximum torque is

\(A = 0.05^2 = 0.0025\ \text{m}^2\), so \(\tau_{\max} = NBIA = 10 \times 0.1 \times 2 \times 0.0025 = 0.005\ \text{N m}\).

BDC motor: commutator

Key idea

Motor: coil + split-ring commutator + brushes + magnet. Each half-turn, commutator swaps contacts so the side that was pushed up now gets reversed current and is still pushed up → continuous rotation. AC on same motor would reverse twice per cycle → vibrates not steady.

Key ideaDetail
BrushesGraphite, low friction; gap causes sparking.
SpeedHigher ε/I gives faster spin; more turns → more torque.

Concept check

If a d.c. motor's battery is replaced by sinusoidal a.c. of same peak, what happens?

Commutator timed for d.c.; a.c. polarity reverses independently, net torque averages near zero → judder.
