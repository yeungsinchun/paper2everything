Section 24.2

Generators and eddy currents

AGenerators: slip ring vs commutator

Key idea

Rotating coil emf \(\varepsilon = N B A \omega \sin\omega t\) (for constant ω, sinusoidal). a.c. generator uses slip rings + brushes → full sine. d.c. generator uses split-ring commutator → polarity flips each half-turn → pulsing d.c. (not smooth without multiple coils). Frequency = rotation rate.

Key ideaDetail
Peakε0 = N B A ω; double speed → double ε0 and double frequency.
Multiple coilsSmooths d.c. output.

Quick check

A generator coil rotates faster. What changes?

ω up → both amplitude (∝ω) and frequency (∝ω) rise.

BEddy currents

Key idea

Bulk conductor in changing flux gets circulating eddy currents → Lenz opposes motion → magnetic braking. Useful (e.g., induction furnace, eddy brake) but wasteful in transformer cores → laminated (thin insulated sheets) to break loops, reduce heating/hysteresis.

Key ideaDetail
DemoMagnet falls slowly in copper tube, fast in plastic tube same size.
CoreLaminated + soft iron reduces hysteresis and eddy loss.

Quick check

Why transformer core is laminated?

Thin insulated layers break eddy loops, less heating, higher efficiency.
