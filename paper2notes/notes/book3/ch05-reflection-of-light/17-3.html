Section 17.3

Mirror image

A plane mirror forms a virtual, upright image the same size as the object, at equal perpendicular distance behind the mirror.

ACore model: Mirror image

Key idea

A plane mirror forms a virtual, upright image the same size as the object, at equal perpendicular distance behind the mirror.

Object distance = image distance

A plane-mirror image is virtual, upright, same size and laterally inverted.

BApply it carefully

Worked example

An object is 0.80 m in front of a plane mirror.

Its virtual image is 0.80 m behind the mirror and is upright and the same size.

Common mix-up

State the condition that applies here, then distinguish the ray, wave pattern and particle motion.

Quick check

An object is 0.8 m in front of a plane mirror. Where is its image?

B. A plane mirror places the virtual image the same perpendicular distance behind it.
