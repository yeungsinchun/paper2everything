Interference

ACore model: Interference

Key idea

Coherent sources have the same frequency and a constant phase difference. Path difference determines constructive or destructive interference.

Constructive: path difference = mλ · Destructive: (m + ½)λ

m is an integer; stable interference requires coherent sources.

BApply it carefully

Worked example

Two coherent waves have λ = 0.30 m and path difference 0.60 m.

The difference is 2λ, an integer number of wavelengths, so the waves arrive in phase and interfere constructively.

Common mix-up

State the condition that applies here, then distinguish the ray, wave pattern and particle motion.

Quick check

Two coherent waves arrive with path difference one wavelength. What interference occurs?

A. An integer-wavelength path difference gives waves in phase.
