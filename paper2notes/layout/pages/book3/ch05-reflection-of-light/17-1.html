Light and vision

We see an object when light from it enters the eye. A luminous object emits light; a non-luminous object reflects light.

  • AModel and key relation
  • BApply the idea

ACore model: Light and vision

Key idea

We see an object when light from it enters the eye. A luminous object emits light; a non-luminous object reflects light.

A visible object sends light into the eye.

Luminous sources emit light; other objects are seen by reflected light.

BApply it carefully

Worked example

A book is visible in a dark room when a lamp is switched on.

The lamp emits light. Light reflects from the book and enters the observer’s eye.

Common mix-up

State the condition that applies here, then distinguish the ray, wave pattern and particle motion.
