Ch.2 summary

Circuit fundamentals recap

Formula sheet

\(I = \dfrac{\Delta Q}{\Delta t}\) — current

\(R = \dfrac{V}{I}\) — resistance definition

\(R = \rho \dfrac{l}{A}\) — resistivity

Ohm's law: \(I \propto V\) only when \(R\) constant

Common mistakes

R vs ρ

R depends on geometry; ρ is material. Same ρ can give different R with different l/A.

Ohm's law myth

R=V/I always defines R, but Ohm only when R constant (linear I–V).
